YU-GI-OH! DUEL CALCULATOR - GAME BOY ADVANCE (.GBA)
====================================================

Novedades incluidas:
- Hasta 6 contadores simultáneos (en modo 6P se organiza como dado de 6 horizontal en 3 columnas x 2 filas: D1-P1/P2, D2-P1/P2, D3-P1/P2 para llevar 3 duelos a la vez).
- Animación visual de dado (cara de 12x12 con puntos cambiando y ligero vaivén antes de fijar el número) y animación de giro de moneda.

Controles en GBA:
- Izquierda / Derecha : Seleccionar dígito (salta de jugador al llegar al extremo)
- Arriba / Abajo       : Sumar / Restar al dígito seleccionado (el primer dígito sube > 9: 8, 9, 10, 11...)
- Botón A             : Confirmar / Siguiente jugador activo
- Botón B             : Tirar dado (1-6) con animación
- Botón L             : Halvear (dividir a la mitad) los LP del jugador activo
- Botón R             : Tirar moneda (Cara / Cruz) con animación
- Select + Izq / Der  : Cambiar cantidad de jugadores (1 a 6; con 5 = dado de 5, con 6 = 3 duelos en 3x2)
- Select + Start      : Reiniciar duelo (todos a 8000 LP)
